# Codex 小说封面流程

使用当前环境的图像生成能力制作封面，不运行上游 GPT-Image API 脚本。

## 输入

从现有上下文提取书名、作者名、题材、核心人物或意象、情绪、目标平台与画幅。只有缺失项会明显改变封面时才询问；作者名可默认不放，平台未指定时优先竖版 2:3。

## 生成

1. 把题材识别转为可见元素：主体、场景、光线、色彩、时代、服装和冲突暗示。
2. 保持一个主视觉焦点，预留书名安全区；缩略图尺寸下仍需辨认题材。
3. 使用 imagegen skill/tool 直接生成。若有参考图，先查看原图，再把必须保留和必须改变的部分写清楚。
4. 书名文字准确性要求很高时，优先生成无字底图，再用适合精确排版的方式加字；不要声称生成模型中的错误文字是准确标题。
5. 检查标题可读性、人物肢体、裁切、安全区、平台比例和内容合规；有明显问题时迭代一次。

## 交付

返回最终图片，并用一句话说明画幅和设计方向。除非用户要求，不附长篇提示词或设计讲解。
